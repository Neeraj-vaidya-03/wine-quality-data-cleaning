# 🍷 Wine Quality Data Cleaning & Exploratory Data Analysis

A comprehensive data analytics project focused on cleaning, engineering features, and analyzing the physicochemical properties of wine to understand quality drivers.

---

## 📌 Project Overview
This project performs end-to-end data processing and exploratory analysis on the Wine Quality dataset using Python. It addresses missing value handling, summary statistics, feature engineering, and custom visualizations using Matplotlib.

---

## 📂 Repository Contents
* `Wine Quality Dataset.csv` - The raw dataset containing chemical analysis metrics of wine samples.
* `Wine_Quality_data.ipynb` - Complete Jupyter Notebook detailing the data cleaning pipeline, Pandas transformations, and visual charts.

---

## 🛠️ Tools & Technologies
* **Programming Language:** Python
* **Data Manipulation:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn
* **Environment:** Visual Studio Code (Jupyter Extension)
* **Version Control:** Git & GitHub

---

## 🔍 Key Steps & Analysis
1. **Data Cleaning & Preprocessing:** Verified missing values, removed duplicate rows, and checked data types across 12 feature columns.
2. **Feature Engineering:** Binned continuous attributes and created derived metrics to highlight key physicochemical trends.
3. **Exploratory Visualizations:** Created scatter plots, distribution plots, and correlation heatmaps to analyze the impact of alcohol content, volatile acidity, and residual sugar on final quality scores.
